# Aptos (page d’accueil)

Déposez ici les fichiers **woff2** licenciés pour le web (ex. via Microsoft / Adobe Fonts) :

- `aptos-regular.woff2` (400)
- `aptos-semibold.woff2` (600)
- `aptos-bold.woff2` (700)
- `aptos-display.woff2` (400)
- `aptos-display-semibold.woff2` (600)
- `aptos-display-bold.woff2` (700)

Sans ces fichiers, la pile utilise Aptos si elle est installée sur l’appareil, sinon Segoe UI / system-ui.
